# D의 식탁 한글 패치

세가 새턴 일본판 **D의 식탁(D no Shokutaku, 2장)** 한글 패치입니다.

## 내려받기

[릴리즈](../../releases/latest)에서 `DnoShokutaku_KR_v0.9.zip` 을 받아
압축 안 `readme.txt` 대로 디스크마다 원본 트랙 1에 적용하세요.

## 바뀌는 것

- 오프닝 내레이션 글자 한글 자막(화면 아래)
- 아버지 대사 동영상 8편 한글 자막
- 제목 로고 «D의 식탁»
- 디스크·저장 안내 화면, 엔딩 마지막 인사(세 가지)

## 알려진 점

- 시험 단계 패치입니다. 잘못된 곳을 알려 주시면 고치겠습니다.
- 음성은 원본 일본어 그대로이고 자막으로만 옮겼습니다.
- 영어로 된 글자(Time Over, The End 등)는 원본 그대로입니다.

## 저장소 구성

- `tools/` — 디스크 읽기·소리 추출·받아쓰기·목소리 분리·동영상 자막 굽기·그림 글자·디스크 빌드·배포 도구
- `data/voice.tsv` — 음성·오프닝 자막(일본어·한국어·시각) · `data/gfx/` — 제목 로고 원본 그림
- `docs/` — 조사 기록
