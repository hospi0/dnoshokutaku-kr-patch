트랙 1번에 패치하시면 됩니다(트랙 2와 cue 는 원본 그대로).

디스크 1  원본md5 : {o1}
          패치md5 : {d1}
디스크 2  원본md5 : {o2}
          패치md5 : {d2}


[ 적용 방법 ]

  1) 원본 디스크 1·2 의 트랙 1 파일을 이 폴더에 복사
       "D no Shokutaku (Japan) (Disc 1) (Track 1).bin"
       "D no Shokutaku (Japan) (Disc 2) (Track 1).bin"
  2) 한글패치_적용.bat 실행 → 이름 끝에 [KR] 이 붙은 파일이 만들어집니다
  3) 만든 파일 이름을 원본 트랙 1 이름으로 바꿔 넣고, 트랙 2와 cue 는 원본 그대로 쓰세요

  직접 적용:
    xdelta.exe -d -s "원본 트랙 1" "{name}_DiscN_Track1.xdelta" "결과 파일"
  (Delta Patcher 같은 xdelta3 GUI 도구로 적용해도 됩니다. 원본이 다르면 xdelta 가 적용을 거부합니다.)


[ 바뀌는 것 ]

  - 오프닝 내레이션 글자 한글 자막(화면 아래)

  - 제목 로고 "D의 식탁"
  - 디스크·저장 안내 화면, 엔딩 마지막 인사(세 가지)


[ 알려진 점 ]

  - 시험 단계 패치입니다. 잘못된 곳을 알려 주시면 고치겠습니다.
  - 음성은 원본 일본어 그대로이고 자막으로만 옮겼습니다.
  - 오프닝의 일본어 글자는 영상에 그려져 있어 그대로 남고, 한글 자막이 화면 아래에 나옵니다.
