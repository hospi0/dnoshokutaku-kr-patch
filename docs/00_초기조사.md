- `0.BIN` 806,454 B(두 장 같은 크기) — SH-2 실행 파일. **평문 SJIS 대사 없음**(SJIS 덩어리 훑기 결과 전부 코드 바이트 우연 일치).

## 판단
- 평문 텍스트가 없다 → 한글화 = ① **음성 자막**(FILM 영상 안 일본어 음성, 소리 든 영상 약 60분 중 대사 분량은 받아쓰기로 확정해야 함) + ② **그림 글자**(위 표).
- 자막 넣는 길 후보: (가) 영상 프레임에 직접 굽기(Cinepak 재인코딩 — 블루 브레이커·벌크 슬래시 moviesub/movenc 계열 재사용) (나) 에너미 제로처럼 VDP1 스프라이트 훅. 288×144 영상이 화면에 어떻게 확대되는지·띠 수·키 프레임 간격부터 실측.
- 짧은 무음 장면 조각이 많아 장면 전환이 잦다 → 자막을 영상에 굽는 쪽이 장면 경계 걱정이 적다(굽기면 대사 든 영상만 다시 굽는다).
